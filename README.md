# InkLife API

> **Phase 0 – Cloudflare Workers Foundation**

A pen lifecycle tracking backend built on Cloudflare-native primitives: Workers + D1 (SQLite) + KV.

[![Cloudflare Workers](https://img.shields.io/badge/Cloudflare-Workers-F38020?logo=cloudflare&logoColor=white)](https://workers.cloudflare.com/)
[![Hono](https://img.shields.io/badge/Hono-v4-E36002?logo=hono&logoColor=white)](https://hono.dev/)
[![Drizzle ORM](https://img.shields.io/badge/Drizzle-ORM-C5F74F?logo=drizzle&logoColor=black)](https://orm.drizzle.team/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.6-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)

## Stack

| Concern | Technology |
|---|---|
| Runtime | Cloudflare Workers |
| Framework | Hono v4 |
| ORM | Drizzle ORM (D1 adapter) |
| Database | Cloudflare D1 (SQLite) |
| Cache / Rate-limit | Cloudflare KV |
| Auth (Phase 1) | JWT via `jose` |
| Validation | Zod |
| Deployment | Wrangler v3 |

## Prerequisites

- **Node.js** 18+
- **Wrangler** v3 (`npm install -g wrangler` or use npx)
- A Cloudflare account (free tier works) — only needed for deploy

---

## 1 · Install

```bash
npm install
```

---

## 2 · Configure local secrets

```bash
cp .dev.vars.example .dev.vars
# Edit .dev.vars and set JWT_SECRET to any string ≥ 16 chars
```

---

## 3 · Create D1 database & KV namespace (first time only)

```bash
# Create D1 database
wrangler d1 create inklife-db

# Create KV namespace for rate limiting
wrangler kv namespace create RATE_LIMIT_KV
```

Copy the `database_id` and KV `id` printed by the commands above into `wrangler.toml`:

```toml
[[d1_databases]]
database_id = "<paste-here>"

[[kv_namespaces]]
id = "<paste-here>"
preview_id = "<paste-here>"
```

---

## 4 · Apply migrations

```bash
# Generate SQL migrations from schema
npm run db:generate

# Apply to local D1 (for development)
npm run db:migrate:local

# Apply to remote D1 (for production)
npm run db:migrate:remote
```

---

## 5 · Seed the database

```bash
# Local
npm run db:seed:local

# Remote
npm run db:seed:remote
```

This inserts the three required pens:
| Pen | Mileage | Flow | Barrel |
|---|---|---|---|
| BIC Cristal Original | 3,000 m | `normal_ballpoint` | `transparent` |
| Flair Writo-meter | 10,000 m | `liquid_rollerball` | `visible_refill` |
| Hauser XO | 1,500 m | `smooth_low_viscosity` | `visible_refill` |

## 6 · Run locally

```bash
npm run dev

```

## 7 · Verify


---

## 8 · Deploy to Cloudflare

```bash
# Set production secrets (once)
wrangler secret put JWT_SECRET

# Deploy
npm run deploy

# Tail live logs
wrangler tail
```

## Environment Variables

| Variable | Where | Required | Description |
|---|---|---|---|
| `ENVIRONMENT` | `wrangler.toml [vars]` | Yes | `development` \| `staging` \| `production` |
| `CORS_ORIGIN` | `wrangler.toml [vars]` | Yes | Allowed CORS origin |
| `ADMIN_EMAILS` | `wrangler.toml [vars]` | No | Comma-separated admin emails |
| `JWT_SECRET` | `.dev.vars` / `wrangler secret` | Yes | ≥ 16 char JWT signing secret |

## Rate Limiting

KV-backed sliding window: **60 requests / 60 seconds per IP**.

Response headers on every request:
```
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 59
X-RateLimit-Reset: <unix-timestamp>
```

429 response includes `Retry-After` header.
